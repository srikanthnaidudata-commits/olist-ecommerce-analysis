# E-Commerce Sales and Customer Insights Dashboard

## Project Overview

This project analyzes e-commerce sales and customer behavior using the Olist dataset. The dashboard was developed in Power BI to provide insights into sales performance, customer purchasing patterns, product performance, and business growth opportunities.

## Business Problem

E-commerce businesses generate large amounts of transactional data. The objective of this project is to transform raw sales data into meaningful business insights that help stakeholders understand customer behavior and sales performance.

## Tools Used

* Power BI
* Power Query
* DAX
* Excel

## Dashboard Features

* Sales Performance Analysis
* Revenue Trend Analysis
* Customer Segmentation
* Product Performance Tracking
* KPI Monitoring
* Interactive Filters and Slicers

## Key Performance Indicators (KPIs)

* Total Sales
* Total Orders
* Average Order Value
* Top-Selling Products
* Customer Count
* Revenue Growth Trends

## Key Insights

* Identified top-performing product categories.
* Analyzed customer purchasing patterns.
* Tracked monthly sales performance trends.
* Evaluated revenue contribution by products.
* Supported business decision-making through data visualization.
